# TechVision Website

## 📌 Project Overview
This project is a responsive company landing page built as part of a technical assessment for the Junior Frontend Developer position.  
It represents a fictional IT company and showcases modern UI design, responsive layout, and basic JavaScript (Vanilla JS) interactivity.

The website includes key sections such as **Hero, Services, About, and Contact** with form validation.

---

## 🚀 Features
- Fully responsive design (Mobile, Tablet, Desktop)
- Responsive **Navigation Bar** with hamburger toggle and dark mode switch
- Hero section with **Call-to-action button** for text and image
- Services section generated dynamically with **loop**
- About section with **stats count-up animation**
- Contact section with **colored icons** for Address, Phone, and Email
- Clean, modern design with hover effects and transitions
- Dark/light mode toggle
- Smooth scrolling
- Animations/transitions

---

## 🛠️ Technologies Used
- **HTML5** – Semantic structure
- **CSS3** – Custom styling, transitions, hover effects
- **Bootstrap 5** – Grid system, responsive layout
- **JavaScript (Vanilla JS)** – Count-up animation, toggle menu
- **Font Awesome** – Icons
