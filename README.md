# TechVision Website

A modern, responsive IT solutions website built with **HTML5, CSS3, Bootstrap, and JavaScript**.  
This project showcases TechVision's services, achievements, and contact information in a professional layout.

---

## 🚀 Features
- Responsive **Navigation Bar** with hamburger toggle and dark mode switch
- Hero section with **order system** for text and image
- Services section generated dynamically with **loop**
- About section with **stats count-up animation**
- Contact section with **colored icons** for Address, Phone, and Email
- Clean, modern design with hover effects and transitions

---

## 🛠️ Technologies Used
- **HTML5** – Semantic structure
- **CSS3** – Custom styling, transitions, hover effects
- **Bootstrap 5** – Grid system, responsive layout
- **JavaScript (Vanilla)** – Count-up animation, toggle menu
- **Font Awesome** – Icons
